# Misiones de matemáticas · 5.º de primaria (México) · v1.02

**Eslogan:** Fichas de matemáticas para 5.º, listas para imprimir y revisar juntos.

**Para quién:** familias y docentes de 5.º de primaria en México que quieren practicar todas las matemáticas del grado, con ayudas que bajan poco a poco.

**Cómo funciona**
1. Abre la página y elige una ficha.
2. Imprímela en carta (una ficha por hoja).
3. Resuelve los tres ejercicios: leer una figura, hacer la operación y un reto.
4. Dobla la hoja y revisen juntos con el solucionario de abajo.

**Incluye:** 15 temas, 90 fichas, 270 ejercicios.

| Función | HTML |
|---|---|
| Elegir y ver ficha | Sí |
| Mostrar respuestas | Sí |
| Imprimir o guardar en PDF (ficha, tema o todo) | Sí |
